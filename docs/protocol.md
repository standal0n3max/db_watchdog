# Протокол задачи: watchdog → commit-suite

Публичная задача строится детерминированно из карточки watchdog. Поля
`TaskInstance` раскладываются так:

| Поле карточки | Куда идёт | Смысл |
|---|---|---|
| `head_sha` | oracle `head` | фиксированная точка; дерево содержит баг и тест |
| `base_sha` | oracle `base` | временная граница отсечки графа |
| `gold_patch` | oracle `reverse_patch` | reverse source patch делает исходник buggy |
| `test_patch` | oracle `test` | скрытый тест, снимается на время агента |
| `fail_to_pass` | oracle `expected_tests` | имена тестов, которые должен починить фикс |
| `statement` | публичный `goal` | очищенный текст без trailers |
| `oracle_command` | oracle `oracle_command` | команда оракула |

## Публичная часть

Публичный JSON содержит только `func`, `area`, `goal`, `contract`, `graded_by`.
Ни эталонного патча, ни содержимого тестов там нет. `graded_by` несёт лишь
имена скрытых файлов.

- `goal` — очищенный statement: trailers (`Reported-by:`, `Author:`,
  `Discussion:`, `Backpatch-through:` и подобные) и служебные ссылки удаляются.
- `area` выводится из subject и изменённых source-путей.
- `contract` извлекается только для новых пользовательских сообщений об ошибках,
  и только если точный литерал сообщения присутствует в скрытом тесте. Если
  тест не проверяет формулировку, сообщение в contract не попадает.

## Приватный oracle

Oracle хранит `head`, `base`, reverse patch, тестовый патч, эталон, список
тестовых файлов, команду оракула и ожидаемые тесты. `graded_by` публичной части
совпадает с именами тестовых файлов oracle.

## Промпт

Промпт повторяет форму commit-suite: системные правила, `Area`, `goal`, при
наличии `contract` — точные тексты сообщений, при наличии `graded_by` — имена
скрытых тестов. В режиме `graph` в конец добавляется просьба использовать три
MCP-инструмента до редактирования; bare-промпт этого текста не содержит.

## Проверки конвертера

`python -m db_pipeline.benchmark validate` проверяет:

- публичная задача не содержит фрагментов diff и лишних полей;
- reverse source patch на `head_sha` даёт buggy source;
- reverse test patch снимает тест;
- `graded_by` содержит только тестовые файлы.
